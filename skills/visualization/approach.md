# Skill: Visual Storytelling

This skill guides the creation of impactful, clear, and professional data visualizations.

## Core Reasoning Principles

1.  **Form Follows Function**:
    *   **Trends over time:** Use Line Charts.
    *   **Comparisons:** Use Bar Charts.
    *   **Relationships:** Use Scatter Plots.
    *   **Parts-to-whole:** Use Stacked Bars (avoid Pie charts for more than 3 categories).

2.  **The "So What?" Test**:
    *   Every chart should answer a question. 
    *   Use a descriptive title that states the finding (e.g., "Sales Spiked 20% in Q4") rather than just the data (e.g., "Sales vs Time").

3.  **Clarity over Complexity**:
    *   Remove chart-junk: minimize gridlines, labels, and borders.
    *   Use color purposefully: highlight the most important series, use neutral colors for others.

4.  **Statistical Context**:
    *   When showing a mean, also show the variance or confidence interval.
    *   Label the axes with units (e.g., "Revenue ($M)").
