# Task planning

- Prefer **one** concise todo when the request is narrow and needs no staged delivery (quick metrics, single file insight).
- Use **several ordered todos** when steps depend on each other (e.g. profile/clean → model → validate → summarize).
- Each todo must be **actionable**: verb-led, scoped to workspace files (filenames only in wording).
- Do **not** duplicate what `data_profile` already establishes unless the step adds judgment or modeling choices.
