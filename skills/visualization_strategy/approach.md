Use this skill when the user wants charts, plots, dashboards, or visual storytelling.

How to think about the visual:
- Choose the chart based on the question, not by habit.
- Use time-series charts for change over time, bars for comparisons, and distribution plots for spread and skew.
- Keep the plot easy to read and aligned with the decision the user is trying to make.
- Avoid misleading scales, clutter, and unnecessary chart variety.

Planning guidance:
- Decide whether a visual alone is enough or whether it should accompany a direct explanation.
- Check whether the data needs reshaping or aggregation before plotting.
- Make titles, axes, legends, and grouping choices explicit when execution is needed.
- If multiple visuals are possible, prefer the one that best answers the user's question with the least cognitive load.
